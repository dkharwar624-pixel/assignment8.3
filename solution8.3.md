I built a magazine or news-style webpage using CSS Grid Areas as required. I created five main sections: a header containing the newspaper name The Daily Grid and date, a navigation bar with categories like World, Politics, Technology, Sports, Business, Culture, a main article section with featured story, large heading, image, and content, a sidebar with trending news cards and advertisement, a secondary section with three small news cards, and a footer with copyright information. I defined a grid container named magazine-container with display grid and set the entire layout using grid-template-areas which allows visual arrangement of sections like a map: I set it as header header on first row, nav nav on second row, main sidebar on third row, secondary secondary on fourth row, and footer footer on fifth row, which clearly shows the magazine structure. I assigned a named grid area to each section using grid-area property: mag-header gets header, mag-nav gets nav, main-article gets main, mag-sidebar gets sidebar, secondary gets secondary, and mag-footer gets footer, making the code highly readable and easy to rearrange. I gave the main article more space than the sidebar by setting grid-template-columns to 2fr 1fr, meaning main gets two fractions (66% width) while sidebar gets one fraction (33% width), just like real newspapers where main story dominates and sidebar is smaller for trending news. I tested different section sizes and alignments by experimenting with different fr values like 3fr 1fr for even larger main, and 1fr 1fr for equal sizes, and also tested alignments by changing justify-items and align-items, and for responsiveness I changed grid-template-areas to single column layout on screens below 900px where all sections stack vertically in order header, nav, main, sidebar, secondary, footer, which is perfect for mobile reading.
